# 営業担当向け 操作手順書

読み手は営業担当。技術用語は使わない。
この道具が売るものは「話しているだけで試作品が完成する」体験そのもの。
**主役は会話**で、画面はその脇に置く。

## 商談前(5分)

- [ ] `https://mvp.example.jp`(自社のURL)をノートPCのブラウザ(Chrome推奨)で開く
- [ ] 画面共有するウィンドウを**このタブだけ**にしておく(通知やメールが映らないように)
- [ ] 「録音を開始」を押し、マイク許可 → 何か話して文字が出ることを確認 → 「停止」
      (この練習分は本番と別の記録になるので気にしなくてよい)
- [ ] 当日の議題をひとこと頭に入れておく: 相手の困りごとを言葉にしてもらう会話が、
      そのまま試作品の材料になる

うまく動かないときは商談を止めない。この道具なしで商談を進め、
後で管理者(開発側)へ連絡する。

## 商談の流れ

### 1. 開始

1. **相手の同意を先に取る。** 例:「会話をその場で文字にして、議事録と試作品づくりに
   使います。音声そのものは保存されません。よろしいですか?」
2. 「録音を開始」を押す。マイク許可を求められたら許可する
3. 画面の一番上に赤い帯(録音中の表示と経過時間)が出れば動いている

### 2. 会話中

- 話が進むと、画面に「課題」「アイデア」などのタブが増えていく。**放っておいてよい**
  (「サマリ」「アクション」は、試作品を作るときと商談を終えたときに増える)
- 相手に見せたいときだけタブを開く。新しく更新されたタブには印が付く
- 「AIが停止しています。文字起こしは続いています」と出ても商談は続けられる。
  記録は残っているので、そのまま話し続けてよい
- **文字起こしが止まったときの表示は2通りある。** どちらも録音は続いているが、
  その間の会話は議事録に載らない
  - 「音声認識が停止しました。ここから先は文字起こしされません。」
    — 会話の途中で止まった場合(こちらが多い)
  - 「音声認識が停止しています。録音は続いています。」
    — 一言も文字起こしできていない場合

### 3. 試作品を作る(山場)

会話の中で自然に言う。拾われる言い回しの例:

> 「じゃあ、**この内容でアプリを作って**みましょうか」
> 「いま伺った話、**試作品作って**みますね」

- 「〜作って」「形にして」等の言葉で、**確認画面**が出る
- 確認画面には**ここまでの議事録**が表示される。相手と一緒に眺めて、
  「この理解で作ります」と口頭で確認してから **「作る」を押す**
- 雑談で誤って出たときは「いいえ」。何も起きずに商談へ戻る
- 確認画面が出ている(はずの)間に言い直すと、**同じ確認がもう一度出る**。
  画面から消えてしまったときは、言い直せば戻ってくる
- 「いいえ」で閉じたあとは、**3分間は同じ言葉でも再び出ない**。
  会話が同じ話題へ戻るたびに確認が出て商談が途切れるのを防いでいる。
  作り直したいときは3分あけて言い直す
- 押してから数分かかる。**待ち時間は説明タイムではなく質問タイム**にする:
  「できあがるまでに、他に困っていることはありますか?」

### 4. 見せる

- できあがると画面にQRコードと「開く」リンク、「URLをコピー」が出る
- **QRは自分の2台目の端末で読む。** 手元のスマホやタブレットで開き、画面共有か
  実機を見せる形で提示する
- **顧客の端末へURLを送らない(現時点の運用)。** 「相手の手元で動く」ほうが体験は
  強いが、URLは合言葉そのもので、渡した先の履歴に残り、転送もできてしまう。
  ここは運用として保留にしてある。**解禁は管理者の判断を待つこと**
- 見せながら必ず言うこと:「これは会話から自動で作った試作です。本開発では
  ここから要件を詰めます」— 期待値を上げすぎない

### 5. 終了

1. 「停止」を押す
2. 少し待つと「サマリ」(議事録)と「アクション」(宿題リスト)のタブが増える。
   停止直後は無い。**1分ほどかかることがある**
3. **「Markdownをまとめてダウンロード」** で記録一式を保存し、お礼メールに添付する。
   このボタンは試作品を作らなかった商談でも出る

## してはいけないこと

- **実在の顧客名・実際の数値を会話や手入力で投入しない。** デモ・試作の範囲では
  仮名・ダミー数値を使う(運用ルール)
- **生成された試作品のURLを誰にも送らない(現時点の運用)。** 自分の2台目の端末で
  開くところまでにする。**このURLは合言葉そのもので、知っている人は誰でも開ける**
  (社内・社外を問わない)。有効期限はセッションと同じ。
  なお、このURLから議事録や文字起こしは読めない — 生成された試作品だけが開く
- 録音の同意を取らずに開始しない

## よくあるトラブル

| 症状 | その場での対処 |
|---|---|
| マイク許可のダイアログが出ない | ブラウザのアドレス欄の鍵マーク → マイクを「許可」。それでも駄目ならページを開き直す |
| 「AIが停止しています」が出続ける | 商談は続けてよい。文字起こしと録音は生きている。試作品づくりだけ諦め、終了後に管理者へ連絡 |
| 「作って」と言ったのに確認画面が出ない | 上の言い回しの例をそのまま、**一息で区切らずに**はっきり言う(途中で間を置くと文が割れて拾えない)。それでも出なければ試作は諦めて口頭で締め、終了後に管理者へ連絡 |
| 確認画面が出たはずなのに消えた | 言い直せば同じ確認が戻ってくる。ページを開き直しても戻ってくる |
| QRが読めない | 「開く」リンクを押して**自分のPCの別タブで**見せる。URLを他人へ送らない(上の運用) |
| 画面が固まった | ページを開き直す。**それまでの記録に戻れる**(同じタブで開き直した場合のみ)。録音は止まるので、相手に一言断って「録音を開始」から新しく始める。前半ぶんのダウンロードは開き直したあとでもできる |
| 停止したのに「サマリ」が出ない | 1分ほど待つ。それでも出なければAIが停止している。「Markdownをまとめてダウンロード」で文字起こしだけは持ち帰れる |

## 管理者向けメモ

- トリガーの言い回し一覧はサーバー側 `trigger.ts` にある。営業の口癖に合わせて追加してよい
- 誤検出が多い商談では環境変数 `TRIGGER_DISABLED=true` で検出だけ止められる。
  **ただし画面から手で始める方法は無い。** これを入れた日は試作品を作れない
- 「3分間は再び出ない」の起点は**確認画面を出した時刻**。閉じた時刻ではないので、
  相談が長引いた場合の実際の待ち時間は3分より短い
